# Mobile Sales Data Analysis (تحلیل داده‌های فروش تلفن همراه)

تحلیل داده‌های فروش ۵ ساله یک فروشگاه تلفن همراه با Python

## 📋 درباره پروژه

این پروژه به تحلیل داده‌های فروش ۵ ساله (۱۳۹۹-۱۴۰۴) یک فروشگاه تلفن همراه می‌پردازد. هدف، شناسایی الگوهای فروش، پرفروش‌ترین محصولات و روند فصلی فروش است.

## 🎯 اهداف پروژه

- پاک‌سازی و آماده‌سازی داده‌های فروش
- تحلیل الگوهای فصلی فروش
- شناسایی پرفروش‌ترین محصولات
- مصورسازی داده‌ها
- استخراج بینش‌های قابل اقدام

## 🛠️ ابزارها و کتابخانه‌ها

- Python 3.10+
- Pandas — تحلیل داده
- NumPy — محاسبات عددی
- Matplotlib — مصورسازی
- Seaborn — مصورسازی پیشرفته

## 📊 خروجی‌های پروژه

- نمودار روند فروش ماهانه
- نمودار پرفروش‌ترین برندها
- تحلیل الگوهای فصلی
- نمودار سهم محصولات از درآمد
